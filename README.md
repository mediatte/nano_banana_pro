# 🍌 Nano Banana - AI 이미지 생성기

Google AI API를 활용한 크롬 익스텐션으로, 간편하게 AI 이미지를 생성하고 편집할 수 있습니다.

## ✨ 주요 기능

### 🎨 두 가지 AI 모델 선택 가능

#### 1️⃣ Gemini 3 Pro Image Preview (v1alpha) ⚡
- **네이티브 이미지 생성**: Gemini 3가 직접 이미지 생성/편집
- **고급 추론**: thinking_level: high - 최고 품질 추론
- **고해상도 처리**: media_resolution_high (1120 토큰)
- **최신 AI**: 2025년 1월 최신 지식 기반
- **고성능**: 65K 입력 토큰 / 32K 출력 토큰
- **자동 폴백**: 실패 시 Flux 모델 (2048x2048)
- 💰 유료: $2 (텍스트) / $0.134 (이미지)

#### 2️⃣ Gemini 3 Pro (프롬프트 개선 + 생성) (추천 ⭐)
- **2단계 처리**: Gemini 2.0 프롬프트 개선 → Gemini 3 Pro 이미지 생성
- **Gemini 2.0 Flash**: 프롬프트를 전문가 수준으로 자동 개선
- **Gemini 3 Pro Image Preview**: Google 네이티브 이미지 생성
- **고급 추론**: thinking_level: high - 최고 품질
- **고해상도**: media_resolution_high
- **한국어 입력 OK**: 자동으로 최적화
- 💎 **100% Google AI** - 순수 Google 기술!

### 1. 텍스트로 이미지 생성 🎨
- 간단한 한국어 설명만 입력하면 AI가 알아서 처리합니다
- 예: "석양이 지는 해변" → 고품질 이미지 생성
- 두 가지 모델 중 선택 가능

### 2. 이미지 편집 ✨
- 기존 이미지를 업로드하고 편집 명령을 입력합니다
- **드래그 앤 드롭** 지원 - 웹 브라우저에서 직접 드래그 가능
- AI가 명령에 따라 새로운 이미지를 생성합니다
- 예: 풍경 사진 + "하늘을 보라색으로" → 편집된 새 이미지

## 🚀 설치 방법

### 1. Google AI API 키 발급

#### 단계별 가이드:
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속합니다
2. Google 계정으로 로그인합니다
3. **"Create API Key"** 버튼을 클릭합니다
4. 프로젝트를 선택하거나 새로 생성합니다
5. 생성된 API 키를 복사합니다 (나중에 다시 볼 수 없으니 안전한 곳에 보관하세요!)

#### 사용 가능한 모델:
- 🧪 **Gemini 3 Pro Image Preview** (실험적) - 이미지 생성 시도
- ⭐ **Gemini 2.0 Flash** (추천) - 프롬프트 개선 및 이미지 분석
- ✅ **Pollinations AI** - 무료 고품질 이미지 생성

#### 무료 할당량:
- **Gemini 3 Pro**: 제한적 무료 사용 가능
- **Gemini 2.0 Flash**: 매일 1,500 요청 무료 ⭐
- **Pollinations AI**: 완전 무료, 무제한 🎉
- 자세한 정보: [Google AI 가격 정책](https://ai.google.dev/pricing)

### 2. 익스텐션 설치

#### 방법 1: Chrome 웹 스토어 (출시 후)
- Chrome 웹 스토어에서 "Nano Banana" 검색 후 설치

#### 방법 2: 개발자 모드로 로드
1. 이 저장소를 클론하거나 다운로드합니다
   ```bash
   git clone [repository-url]
   ```

2. Chrome 브라우저를 열고 `chrome://extensions/`로 이동합니다

3. 우측 상단의 "개발자 모드"를 활성화합니다

4. "압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭합니다

5. 다운로드한 폴더를 선택합니다

6. 익스텐션 아이콘을 클릭하면 오른쪽 사이드바에 전체 화면으로 표시됩니다!

### 3. 아이콘 추가 (개발자 모드 사용 시)
익스텐션이 정상 작동하려면 `icons` 폴더에 다음 크기의 아이콘이 필요합니다:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

아이콘을 직접 만들거나 온라인 아이콘 생성 도구를 사용할 수 있습니다:
- [Canva](https://www.canva.com/)
- [Figma](https://www.figma.com/)
- [Icon Generator](https://www.favicon-generator.org/)

바나나 이모지(🍌)를 사용한 간단한 아이콘을 추천합니다.

## 📖 사용 방법

### 첫 설정 (최초 1회)
1. 익스텐션 아이콘을 클릭하여 사이드 패널을 엽니다
2. **⚙️ API 설정** 섹션에서:
   - **AI 모델 선택**: Gemini 3 Pro (최신) 또는 Gemini 2.0 Flash (안정적) 선택
   - **Google AI API 키** 입력
3. **저장** 버튼을 클릭합니다
4. 상태가 "✓ 연결됨"으로 변경되면 준비 완료!

### 텍스트로 이미지 생성 🎨
1. **"텍스트로 생성"** 탭을 선택합니다
2. 원하는 이미지를 한국어로 설명합니다
   - 💡 예: "석양이 지는 해변의 야자수"
   - 💡 예: "우주를 떠다니는 고양이, 사실적인 스타일"
   - 💡 예: "네온 불빛의 미래 도시"
3. **"이미지 생성"** 버튼을 클릭합니다
4. AI가 자동으로:
   - ① Gemini가 프롬프트를 전문가 수준으로 개선
   - ② Flux AI가 초고해상도 이미지 생성 (2048x2048)
5. 생성된 이미지를 다운로드하거나 새 탭에서 열 수 있습니다
   - 💾 **다운로드**: 이미지를 바로 저장
   - 🔗 **새 탭에서 열기**: 전체 화면으로 보기, 우클릭으로 복사/저장 가능

### 이미지 편집 ✨
1. **"이미지 편집"** 탭을 선택합니다
2. 편집하고 싶은 이미지를 업로드합니다 (JPG, PNG 등)
   - 🖱️ **드래그 앤 드롭**: 
     - 파일 탐색기에서 이미지 파일을 드롭존으로 드래그
     - 구글 이미지 검색에서 이미지를 직접 드래그
     - 다른 웹사이트의 이미지를 드래그
   - 📁 **파일 선택**: 드롭존을 클릭하여 파일 탐색기에서 선택
   - 💡 **CORS 자동 처리**: 접근 제한이 있는 이미지도 자동으로 처리
3. 편집 명령어를 한국어로 입력합니다
   - 💡 예: "하늘을 보라색으로 바꿔줘"
   - 💡 예: "배경을 흐릿하게 만들어줘"
   - 💡 예: "빈티지 필름 스타일로 변환"
4. **"이미지 편집"** 버튼을 클릭합니다
5. AI가 자동으로:
   - ① Gemini Vision이 이미지 분석
   - ② 편집 의도를 이해하고 프롬프트 생성
   - ③ 새로운 이미지 생성
6. 생성된 이미지를 다운로드하거나 새 탭에서 열 수 있습니다
   - 💾 **다운로드**: 이미지를 바로 저장
   - 🔗 **새 탭에서 열기**: 전체 화면으로 보기, 우클릭으로 복사/저장 가능

## 🐛 문제 해결

### API 키 관련

**❌ "API 요청 실패" 오류**
1. API 키를 올바르게 복사했는지 확인
2. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 API 키가 활성화되어 있는지 확인
3. API 키에 Gemini와 Imagen 사용 권한이 있는지 확인

**❌ "무료 할당량 초과" 오류**
1. [Google Cloud Console](https://console.cloud.google.com/)에서 사용량 확인
2. 다음 날까지 대기 (무료 할당량은 매일 리셋됩니다)
3. 또는 결제 정보를 등록하여 유료로 사용

### 이미지 생성 관련

**❌ 이미지가 생성되지 않는 경우**
1. 프롬프트를 더 구체적으로 작성해보세요
   - 나쁜 예: "고양이"
   - 좋은 예: "햇살 아래 앉아있는 주황색 고양이, 사실적인 스타일"
2. 네트워크 연결을 확인하세요
3. 브라우저 콘솔(F12)에서 에러 메시지를 확인하세요

**❌ 이미지 편집이 의도대로 안 되는 경우**
1. 편집 명령을 더 명확하게 작성하세요
2. 업로드한 이미지가 선명하고 고품질인지 확인하세요
3. 지원되는 이미지 형식인지 확인하세요 (JPG, PNG, WebP)

**❌ 드래그 앤 드롭이 작동하지 않는 경우**
1. **F12**를 눌러 개발자 도구를 엽니다
2. **Console** 탭을 선택합니다
3. 이미지를 드래그해보고 콘솔에 로그가 나타나는지 확인:
   - `🎨 드래그 엔터!` - 드래그가 감지됨
   - `🎉 드롭 이벤트 발생!` - 드롭이 감지됨
   - `✅ 파일 드롭 감지` - 파일 처리 시작
4. 로그가 나타나지 않으면:
   - 익스텐션을 새로고침해보세요
   - 이미지 편집 탭에 있는지 확인하세요
   - 드롭존(점선 박스)에 정확히 드롭하세요
5. CORS 오류가 발생하면:
   - 자동으로 프록시를 통해 로드를 시도합니다
   - 실패 시 이미지를 다운로드 후 직접 업로드하세요

### 익스텐션 관련

**❌ 익스텐션이 로드되지 않는 경우**
1. `icons` 폴더에 필요한 아이콘 파일이 있는지 확인
2. `chrome://extensions/`에서 에러 메시지 확인
3. Chrome 브라우저를 재시작

**❌ 사이드 패널이 열리지 않는 경우**
1. Chrome 버전이 114 이상인지 확인 (Side Panel API 요구사항)
2. 익스텐션을 새로고침 (🔄 버튼 클릭)
3. Chrome을 최신 버전으로 업데이트
